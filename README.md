## 🛠️ What I'm building

| Project | What it is |
| --- | --- |
| **[Dotify](https://github.com/knzeng-e/dotify)** · [dotify.dot.li](https://dotify.dot.li) | A decentralized cultural hub where music becomes a live social connector. Artists publish rights-managed works through their own on-chain runtime; listeners share a real-time room from a single link. React + Vite, Solidity on Paseo Asset Hub, WebRTC, IPFS. |
| **[Polkadot EVM Smart Runtime](https://github.com/knzeng-e/polkadot-evm-smart-runtime)** | The ERC-2535 Diamond pattern applied to Polkadot execution: the proxy becomes a long-lived `SmartRuntime` and facets behave like upgradeable pallets. Gives EVM contracts a forkless-upgrade workflow and a way past the single-contract bytecode ceiling. Solidity + PolkaVM/`resolc`. |
| **[Product Builders Hackademy](https://github.com/knzeng-e/polkadot-builders-hackademy)** | A source-checked "zero to hero" course for building on the Polkadot Products Devnet, following one capstone — *Humanity Care Commons* — through nine phases, from host detection to consent-based on-chain support. Each chapter ties a human mission to an engineering decision, verified as a Builder Proof. |
| **[Scrutinder](https://github.com/knzeng-e/Scrutinder)** | A civic swipe app to rank the 837 measures of *L'Avenir en Commun*. Votes aggregate in real time and every tally ships with a public SHA-256 integrity hash, so anyone can verify the numbers were not altered. |
| **[KemFlix](https://github.com/knzeng-e/KemFlix)** | A Web3 media library for the Kemet cultural community — video, audiobooks and e-learning, with membership recorded on-chain rather than owned by a platform. Built on EIP-2535 Diamonds with an `AnkhToken` and a `Membership` facet. React + ethers + Hardhat. |
